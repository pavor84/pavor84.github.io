# Адвент-календарь Кота Учёного

Код календаря, сценарии на 22 будних дня декабря 2026 года и исходники анимационных проб. Опубликованная страница — `advent/index.html`.

## Изменения и сборка

Работайте из папки `advent`. Задания календаря записаны в `work/make_calendar_html.py`, постановка и реплики для сценариев — в `work/current-scenes.txt`. Сценарии используют задания и ссылки из сгенерированного HTML.

```sh
python3 -m pip install -r requirements.txt
python3 work/make_calendar_html.py
python3 work/build_advent.py
python3 work/pilot-dec01/rebuses.py
```

Генератор HTML использует `outputs/cat-reference.jpg` и системный Arial Bold на macOS. Обновлённый HTML сначала записывается в `outputs`. После проверки для публикации скопируйте его в `index.html`. Этот HTML содержит изображения, встроенные в исходную опубликованную страницу.

- `work/pilot-dec01` — пилот первого выпуска, музыка, рендер и скрипт озвучки. SpeechKit читает ключ из `~/.aistudio`.
- `work/animation-tests/rig2d` — послойная 2D-проба.
- `work/animation-tests/astra3d` — гибридная проба Blender по иллюстрации A.
- `work/animation-tests/rig3d` — ранний упрощённый 3D-тест.
- `work/animation-tests/i2v/prompt.txt` — параметры пробы из двух ключевых кадров.

Видео, изображения, звуковые дорожки, сцены Blender и документы хранятся локально. Готовые материалы находятся в `outputs`, а текстуры для пересборки — рядом с соответствующими скриптами в `work`. Свежий клон получает текстовые исходники. Для пересборки добавьте локальные ресурсы.
